# mit-assets

Bibliothèque d'images publiques de MIT Marketing, servie en CDN via **jsDelivr**.

## Pattern d'URL
```
https://cdn.jsdelivr.net/gh/dannyyefet/mit-assets@main/<chemin>
```
Exemple : `.../mit-assets@main/gemsmile/emails/festival/festival-11.jpg`

## Arborescence
```
<client>/
  emails/        images des mails (optimisées web, <300ko)
  pages/         visuels des pages / lead magnets (pied de biche)
  social/        carrousels, posts
```

## Règle
Repo **PUBLIC** = tout est visible et indexable. On n'y met QUE des visuels
destinés à la diffusion. Jamais de data client, capture interne, ou fichier sensible.
